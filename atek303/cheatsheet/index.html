Quick start

  1. PLAY starts the pattern.
  2. K1–K4 cutoff, reso, env mod, decay.
  3. SEQ a brand-new acid line.
  4. ENV LFO ARP mutate it; REC undoes.
  5. Press a key: the line transposes, like on a 303.
  6. SAVE twice keeps it as a preset with an acid name.

DENSITY, RANGE, ACCENTS and SLIDES regrow the pattern from its seed in real time. SCALE and ROOT change at the output: the line keeps its shape. Up to 64 steps: 4 pages of 16, the page playing on view. Signal: voice → drive → chorus → ping-pong delay (synced) → plate reverb.

Presets · 32 slots

SAVE opens the save screen: PRESETS picks the slot, SELECT a new acid name, SAVE stores everything (pattern, voice, effects, tempo, scale, root); over a used slot it asks OVERWRITE? NO / YES. Any other button cancels.

12 factory presets in slots 1–12; a new FM-1 starts on 01. Turn PRESETS: the list opens and loads each preset as the cursor reaches it; while playing it waits for the end of the pattern, like a 303 (NEXT). ENV twice deletes, SAVE saves on that slot, HOME closes (or 6 s untouched).

MIDI

In: stopped, notes play the voice; running, they transpose. Clock, start, stop and continue drive the sequencer. Out (USB): the keys and the sequencer's notes (accent 127); clock out on request. Channels in OPTIONS.

Install · leave · rescue

Install from The Firmware Hub (Chrome or Edge), charged battery, cable straight in. It carries the Felucca update loader: any installer can put another firmware or M-VAVE's back.

Fails to start twice? It drops to a safe mode (PLAY retries, REC updates). REC held at power-on: the chip's update mode.
