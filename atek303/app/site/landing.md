# ATEK303

A TB-303 style acid machine for the M-VAVE FM-1, with its own pattern generator: press PLAY and a line plays.

Version {{VERSION}}. Installing is at your own risk; the installer can put M-VAVE's own firmware back.

- [Try it in the browser](../play/): the same code the FM-1 runs, with sound. No FM-1 needed.
- [Install](install/): from Chrome or Edge, with the FM-1 connected by USB.
- [Back up your presets](backup/): before you change firmware, and to put them back after.
- [Cheat sheet](../cheatsheet/): every button and page on one sheet.
- [Download {{PKG}}](firmware/{{PKG}}): for the command-line installer, `python3 tools/fm1_install.py {{PKG}}`.
- [Source](https://github.com/animatek/FM1-Animatek): GPL-3.0-or-later. Built on fm1-base (Charles Vestal) and
  felucca-bsp, from Felucca by Leo Kuroshita, Hügelton Instruments.
